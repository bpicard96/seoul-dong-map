# Seoul Dong Map

A phone-friendly map of Seoul's 25 districts and 467 legal dongs (법정동). Mark neighborhoods as visited, want to visit or worthwhile, write notes, and save Naver Map links to places.

Open the site on a phone and add it to the home screen to use it like an app. Marks are stored only on the device that made them; use **Save a backup file** to keep a copy.

Boundaries: [southkorea/seoul-maps](https://github.com/southkorea/seoul-maps) (2015 juso legal-dong outlines, simplified). Dong lists: Seoul Metropolitan Government.
